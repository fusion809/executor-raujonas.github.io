# Executor extension fork with click actions
I wanted click actions and tooltips for the [Executor extension](https://github.com/raujonas/executor); this is my fork to achieve this. It was forked from version 30 of the upstream extension. The default click actions are those I use.

The open-wallpaper.sh and updates_no.sh scripts called by this extension are defined in [lfs-scripts](https://github.com/fusion809/lfs-scripts). This extension assumed it is located ~/.
